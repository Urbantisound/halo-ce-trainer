FAQ

Questions, Answered

Everything you need to know before you load the trainer into your campaign.

Is the Halo: Campaign Evolved Trainer free?

Yes — completely free and open source. There are no paid tiers, subscriptions, or locked features. You can download it from gitscore.cc and inspect the source yourself.

Which Windows versions are supported?

The trainer loader runs on Windows 10 and Windows 11 (64-bit). It's a portable executable, so no installation or admin dependencies are required beyond what the game itself needs.

Can I use it in multiplayer?

No. This trainer is built strictly for the Halo: Campaign Evolved single-player campaign and offline modding. Using it in any multiplayer or matchmaking mode is against the rules and is not supported.

Do the cheats carry over between missions?

Toggles persist while the trainer is attached to the game process. If you restart the game, simply relaunch the loader and re-enable the features you want — each toggle applies live without restarting the mission.
